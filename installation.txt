Instructions d'installation du Carnet d'adresses

1. Prérequis
   - Python 3.8 ou supérieur installé
   - pip (gestionnaire de paquets Python)
   - Git (pour cloner le projet)

2. Installation du projet
   a. Cloner le dépôt :
      git clone https://github.com/Meyou25/carnet-adresses.git
      cd carnet-adresses

   b. Créer un environnement virtuel :
      python -m venv venv
      
   c. Activer l'environnement virtuel :
      - Sur Windows : venv\Scripts\activate
      - Sur Linux/Mac : source venv/bin/activate

   d. Installer les dépendances :
      pip install -r requirements.txt

3. Configuration de la base de données
   a. Appliquer les migrations :
      python manage.py migrate

   b. Créer un superutilisateur :
      python manage.py createsuperuser
      - Suivez les instructions pour créer un compte administrateur

4. Configuration des fichiers statiques
   a. Collecter les fichiers statiques :
      python manage.py collectstatic

5. Lancement du serveur
   a. Démarrer le serveur de développement :
      python manage.py runserver

   b. Accéder à l'application :
      Ouvrir un navigateur et aller à : http://127.0.0.1:8000/

6. Fonctionnalités disponibles
   - Gestion des contacts (ajout, modification, suppression)
   - Recherche de contacts
   - Catégorisation des contacts
   - Mode sombre/clair
   - Interface responsive
   - Gestion des images de profil

7. Dépannage
   - Si vous rencontrez des erreurs lors de l'installation des dépendances :
     pip install --upgrade pip
     pip install -r requirements.txt --no-cache-dir

   - Si la base de données ne se crée pas correctement :
     python manage.py makemigrations
     python manage.py migrate

8. Sécurité
   - Ne partagez jamais vos informations de connexion
   - Gardez votre fichier settings.py sécurisé
   - Changez le mot de passe administrateur régulièrement

Pour toute question ou problème, n'hésitez pas à ouvrir une issue sur GitHub.
